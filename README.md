# UltimateWindowsOptimizer
Продвинутый PowerShell-скрипт для глубокой оптимизации Windows 10/11 под киберспорт, ресурсоемкие игры и ИИ. Инструмент снижает инпут-лаг, настраивает таймеры ядра, MMCSS, HAGS и MSI Mode, отключает телеметрию, а также тонко адаптирует планировщик P/E-ядер и электропитание для максимального FPS.
